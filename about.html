数据来源与接入状态

下表为实测结果，不是声明性描述。标记「需凭据」的来源在未配置 key 时自动降级，不影响页面渲染。 外部海报数据最近一次抓取：2026年9月23日 16:25，共 34 条。

来源用于接入方式状态备注
TMDb趋势片单、影片元数据、海报图库REST API（需 TMDB_API_KEY）/ 官方图库页解析（无需 key）需凭据未配 key 时自动降级：趋势数据跳过，海报改从 TMDB 图库页解析直链。
猫眼专业版实时票房 Top 10（今日票房、占比、场次、累计）本机 Chromium 无头浏览器 + CDP，读取 dashboard 接口已接入票房数字为字体加密，用 WOFF cmap 字形顺序 + canvas 字形匹配求解，并以「今日票房 ÷ 占比 = 当日总票房」一致性校验；校验不通过则不输出数字。
豆瓣电影正在上映榜单的片名与评分HTTP 抓取公开榜单页已接入仅抓榜单页片名与评分，不抓短评与用户内容；请求间隔 3 秒。
IMP Awards历年院线海报原图直链HTTP 抓取影片页，解析 posters/*.jpg已接入按年份目录组织，部分影片 slug 与片名不一致会导致 404，属预期内失败。
Letterboxd影片页面主视觉与出处跳转HTTP 抓取影片页 og:image已接入其图片 CDN 对外链请求返回 403，因此站内主要作为出处跳转与预览。
Fanart.tv无字超清海报与艺术图REST API（需 FANART_API_KEY）需凭据未配 key 时跳过；站点页面作为跳转资源库保留。
MoviePosterDB / Wikimedia Commons多语言版本海报、自由许可素材仅提供跳转链接仅跳转MoviePosterDB 对本机请求返回 403；Wikimedia 域名在当前网络环境不可达。两项均保留为人工检索入口。
抓取与自检命令
  • node scripts/fetch-daily.mjs抓取 TMDb 趋势 + 猫眼票房 + 豆瓣在映，合并写入 data/daily_movies.json
  • node scripts/fetch-posters.mjs抓取 TMDB 图库 / IMP Awards / Letterboxd 海报直链，写入 data/remote_posters.json
  • node scripts/probe-sources.mjs探测信息源可用性（HTTP 状态、响应体积、耗时）
  • node scripts/probe-posters.mjs探测海报资源库可达性
  • node scripts/smoke.mjs构建后冒烟：全部路由与静态资源状态码 + 关键文案断言
